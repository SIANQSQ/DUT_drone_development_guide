## 电池简介

50PL 6S2P 是一款大容量高压锂聚合物（LiPo）电池，专为大型多旋翼无人机设计。"6S2P" 表示该电池由 **6 串 2 并** 共 12 颗电芯组成——6 颗电芯串联提供高压，每组 2 颗电芯并联提升容量。

本项目中，50PL 6S2P 作为整机的 **主动力电池**，通过 [PMU Lite](pmu-lite.md) 电源管理模块向飞控、电调、机载计算机、舵机等全部设备供电，是整个无人机系统的能量核心。

## 使用指南

### 1. 安装与固定

将电池安装在机身碳板下层的电池仓内，使用 **防滑电池绑带** 或 **魔术贴扎带** 牢固固定：

- 电池重心尽量靠近飞行器几何中心，确保飞行姿态平衡。
- 电池与碳板之间加垫 **EVA 防震海绵**，减少高频振动对电芯的影响。
- 确保电池线缆不与螺旋桨旋转平面干涉，使用扎带将多余线缆束紧固定。
- 电池周围预留散热空间，避免紧贴电调等发热器件。

### 2. 电气连接

```
电池（50PL 6S2P）→ PMU Lite → 分电板 → 飞控 / 电调 / 机载计算机 / 舵机
```

- 首先连接 PMU Lite 的电源输入线至电池 XT90/XT60 插头。
- **上电前**务必核对正负极性，反接将烧毁 PMU Lite 及后续全部设备！
- 上电顺序：先插防打火回路（若有），待电容预充完成后，再插紧主插头。

### 3. 充电操作

> **充电必须在防火安全环境中进行，严禁无人值守充电！推荐使用平衡充电器（如 ISDT、ToolkitRC 等品牌）。**

#### 充电参数设置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **充电模式** | Balance Charge（平衡充） | 确保各电芯电压一致 |
| **充电电流** | 8A(在平衡充设置的电流)  最大充电电流1c
| **目标电压** | 25.2V (4.2V / Cell) | 不可过充 |


#### 充电步骤

1. 将电池主电源线连接充电器电源输出端。
2. 将平衡充线的 JST-XH 插头插入充电器平衡口。
3. 选择 **LiPo → Balance Charge → 6S (22.2V)**。
4. 设置充电电流（推荐 8A），确认后启动充电。
5. 充电过程中监控各电芯电压，确保电芯间压差 ≤ 0.02V。
6. 充电完成后，先断开主电源线，再拔平衡充线。

### 4. 放电与飞行监控

- 飞行中通过飞控（QGC 地面站）实时监控电池电压。
- **低压报警阈值**：建议设置 `3.5V / Cell`（整包 21.0V）为一级报警，`3.3V / Cell`（整包 19.8V）为强制返航。
- 落地后整包电压不应低于 21.0V（3.5V / Cell），长期过放会不可逆地损坏电芯。
- 电池放电后应冷却至室温后再进行充电。

### 5. 储存与保养

- **长期储存（> 7 天不使用）**：将电池充/放电至 **储存电压 22.8V (3.80～3.85V / Cell)**。
- 储存环境：干燥（湿度 40%～60%）、阴凉（15°C～25°C），避免阳光直射和高温。
- 每隔 1～2 个月检查一次储存电压，若低于 3.7V/Cell 需补电至储存电压。
- 电池表面应保持清洁干燥，定期检查热缩膜无破损、无鼓包。
- 建议使用 **防爆电池袋** 或 **弹药箱** 存放电池，降低火灾风险。

## 安全注意事项

!!! danger "锂电池安全警告"
    锂聚合物电池含有大量能量，使用不当可能导致火灾、爆炸或严重人身伤害。请严格遵守以下安全规范：

- [ ] **严禁过充**：单电芯充电电压不得超过 4.2V。
- [ ] **严禁过放**：单电芯放电电压不得低于 3.0V，建议不低于 3.3V。
- [ ] **严禁短路**：正负极直接接触将引发大电流放电，瞬间产生高温和火灾。
- [ ] **严禁挤压穿刺**：电芯受损可能导致内部短路，引发热失控自燃。
- [ ] **严禁在无人看管情况下充电**。
- [ ] **充电时远离可燃物**，充电区域配备灭火器（D 类或锂电池专用）。
- [ ] **运输时**必须使用电池防爆包装，放电至 30% 电量以下（符合航空/快递安全要求）。
- [ ] **废弃电池**应送至专业电池回收点处理，严禁随意丢弃或投入火中。

## 常见故障排除

| 故障现象 | 可能原因 | 解决步骤 |
|---------|---------|---------|
| 电池充不进电 | 过放导致电芯损坏、充电器故障 | 检查各电芯电压；若单电芯 < 2.5V，电池已损坏需更换 |
| 电芯电压不一致 | 长时间未做平衡充电 | 使用平衡充电模式，小电流（0.5C）充分平衡；若压差持续过大需更换 |
| 电池鼓包 | 过充、过放、高温储存导致内部产气 | **立即停止使用**，将电池移至室外安全处，联系专业回收处理 |
| 飞行时间明显缩短 | 电池老化、电芯内阻增大 | 测量内阻，若单电芯内阻 > 10mΩ 或压差过大，建议更换 |
| 插头打火严重 | 电容充电浪涌 | 更换为防打火插头（XT90-S 或 XT60），或加装预充电回路 |
| 电池异常发热 | 放电电流过大、电芯内部短路 | 立即停止使用，检查负载是否超规格；冷却后测量内阻 |
