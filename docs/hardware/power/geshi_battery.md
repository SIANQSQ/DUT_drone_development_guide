# 格氏（ACE）6S  动力电池

锂电池基础知识及维护保养（请时刻遵循，最好打印后供随时对照）：
*****************************************************************************
1.【新收到电池】 新电池出厂仅有少量电，不要使用，务必使用标准平衡充电器充满后再使用。平时如不急，推荐0.5C左右充电，例如4000mAh电池用2A左右电流充电，慢一点有利电池使用寿命。
*****************************************************************************
2.【满电和使用过程中的电压下降范围】 电池充满时电压为单片4.2v左右（高压版为4.35V）。用电时开始逐渐电压缓慢降低，单片电芯建议一般不能用到低于3.6v，特殊情况不得低于3.3v，请在类似BB响的电压监控设备上设置好报警阈值(总电压下限计算：2s电池由两片电芯叠加,总电压不得低于6.6v；3s三片叠加，总电压不得低于9.9v，以此类推）。过放电会导致电池损坏、鼓胀，充电器会拒绝充电，也不属质保范围。切忌放电到设备跑不动才断电，更禁止未断开设备连接、直接搁置！
*****************************************************************************
3.【长期保存注意事项】 超过24小时不用请断开和航模及BB响连接，保持“半电”存放！单芯电压维持在3.75-3.85v较适当（如电池满电和无电就长期存放，极易鼓胀），一般充电器都有存储模式。约45到60天的周期，对电池充放激活一次，切勿长期搁置不管！

## 使用与连接

- 使用支持 **LiPo 6S 平衡充电** 的充电器；主电源线接充电器输出，平衡线接对应的 6S 平衡接口。
- 充电器电池类型应设为 **LiPo**，而非 LiHV；该型号标称电压为 22.2V，即标准 6S LiPo 平台。
- 接入无人机前，检查 XT60 正负极、线缆绝缘层和电池外皮。发现鼓包、漏液、破损、异常发热或电芯压差异常时，停止使用并隔离电池。
- 将电池固定在机架重心附近，并用电池绑带可靠限位；主电源线和余额线不得进入桨叶旋转区域，也不得被碳板压伤。

## 充电、放电与存放

格瑞普在其 LiPo 资料中说明：标准 LiPo 单节标称电压为 3.7V、满电电压为 4.2V，建议储存电压为 3.8 ± 0.1V/节；并建议使用恒流恒压充电方式。因此本电池应遵循以下边界：

| 场景 | 建议设置或检查项 |
| --- | --- |
| 充电模式 | LiPo 6S 平衡充电 |
| 充满目标 | 25.2V（4.2V/节 × 6） |
| 长期存放 | 约 22.8V（3.8V/节 × 6） |
| 飞行前 | 检查各节电压一致性、外观及插头状态 |
| 飞行后 | 待电池冷却后再充电；不长期满电存放 |

## 维护保养规范

!!! warning "随电池保存"
    以下操作规范由本项目提供，应在使用本电池前阅读并遵循。建议打印后随充电器或电池箱保存，作为飞行前后的核对清单。

### 新电池首次使用

- 新电池出厂仅带少量电量，**不得直接使用**；先用标准 LiPo 平衡充电器充满，再投入使用。
- 日常不赶时间时，推荐以约 **0.5C** 充电。本电池容量为 3300mAh，0.5C 对应 **1.65A**；较低充电电流有利于延长使用寿命。

### 使用电压与告警

- 标准 LiPo 单节满电约为 **4.2V**；本电池为 6S，整包满电为 **25.2V**。
- 放电时，建议单节电压不低于 **3.6V**；特殊情况下不得低于 **3.3V**。本 6S 电池对应的整包最低电压为 **19.8V**（3.3V × 6）。
- 在 BB 响或飞控遥测等电压监控设备中设置告警阈值，并在达到阈值后结束飞行、断开负载。
- 过度放电可能造成电池损坏或鼓胀，且充电器可能拒绝为过放电池充电。不得等设备无法运转才断电，也不得让已连接设备的电池直接搁置。

### 长期存放

- 超过 24 小时不使用时，断开电池与航模、BB 响及其他负载的连接。
- 以半电状态储存，单节电压保持在 **3.75V 至 3.85V**；本 6S 电池对应整包约 **22.5V 至 23.1V**。充电器的 Storage（存储）模式通常可完成此操作。
- 每 **45 至 60 天**进行一次充放电激活和检查，不要长期搁置不管。

!!! danger "安全要求"
    LiPo 电池具有高能量密度。充电时必须全程有人看管，并远离可燃物；严禁短路、反接、挤压、穿刺或使用受损电池。若需要设置飞控低电压告警、电调电流限制或充电电流，请以电池实物说明书和整机动力系统的实测结果为准，官网型号页面未给出这些型号专用阈值。

## 安装前核对

- [ ] 电池标签与本页型号一致：3300mAh、22.2V、6S1P、45C、XT60。
- [ ] 电池外形尺寸 41.6 × 44 × 141 mm 能放入电池仓，绑带能完全覆盖并锁紧。
- [ ] 机体含电池后的重心符合设计要求。
- [ ] XT60 接头极性、额定电流、线径和电调输入电压均满足整机设计。
- [ ] 充电器支持 LiPo 6S 平衡充电，且平衡线接口匹配。
- [ ] 超过 24 小时不飞行时，电池已与所有设备断开并转入储存电压。
