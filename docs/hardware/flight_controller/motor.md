# 电机 — 郎宇 X4112S

## 电机简介

郎宇（SUNNYSKY）X4112S 系列无刷直流电机，专为多旋翼无人机设计的高性能外转子电机。该系列电机以其高效的磁路设计、轻量化结构以及出色的散热性能在行业中广泛应用。根据 KV 值不同，可适配 4S~6S 锂电池和不同尺寸的螺旋桨，满足从长航时到重载荷等多种飞行需求。

本项目中采用 **郎宇 X4112S** 搭配 **好盈电调** 及 **CUAV X25 EVO** 飞控，为无人机提供稳定可靠的动力输出。

## 外观与结构

X4112S 采用银灰色铝合金外壳，表面阳极氧化处理，具有高硬度和良好的抗腐蚀能力。转子外圈设计有散热槽，旋转时利用离心力形成气流，帮助线圈和磁钢散热。

电机出线为标准 3 根相线（黑色），线材为耐高温硅胶线，焊接端预留镀锡。底部有十字形安装底座，4×M3 螺丝孔位，适配标准无人机机臂电机座。

## 安装步骤

### 1. 固定电机

将电机放置于机臂电机座上，使用 4 颗 M3×8mm 内六角螺丝配合弹簧垫圈固定。

```bash
# 推荐螺丝扭矩（参考）
M3 不锈钢螺丝：0.8 ~ 1.0 N·m
```

- 螺丝需涂抹少量厌氧螺纹胶（如乐泰 243），防止飞行震动导致松脱。
- 四颗螺丝按对角线顺序逐步拧紧，确保电机受力均匀。

### 2. 安装螺旋桨

将桨座安装于电机轴上，确认桨座与电机轴平头对齐。放入螺旋桨后，使用专用桨座螺母拧紧。

> **重要**：确保螺旋桨方向与电机转向匹配（正桨/反桨），安装错误将导致飞行失控。

### 3. 连接电调

电机三根相线分别连接到电调的三根输出线，任意顺序连接即可（电机转向错误时可任意对调两相）。

| 电机相线颜色 | 电调输出线 | 说明 |
|------------|-----------|------|
| 黑色 | 任意 | 三根线任意对插 |
| 黑色 | 任意 | — |
| 黑色 | 任意 | 若反转则对调任意两相 |

## 与电调的配合

X4112S 电机需配合无刷电调（ESC）工作，推荐使用好盈 XRotor 40A 或 60A 电调，支持 6S 电压。

### 电调设置（推荐参数）

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 电机方向 | `Normal` / `Reverse` | 根据桨的安装方向设置 |
| 电机启动功率 | `Medium` | 避免低压启动抖动 |
| 油门行程校准 | `自动` | 首次使用需校准 |
| 刹车 | `OFF` | 多旋翼模式下通常关闭 |
| 低压保护 | `Soft Cut` | 低电压时降低功率而非直接断电 |
| 进角 | `Auto` 或 `15°` | 配合外转子电机特性 |
| PWM 频率 | `8 kHz` ～ `16 kHz` | 适中值可兼顾效率与响应 |

> 电调设置可通过好盈 USB Linker 或调参卡进行，具体参见 [电调文档](esc.md)。

## 维护与注意事项

### 飞行前检查

- [ ] 检查电机转动是否顺畅，无异物卡滞
- [ ] 检查螺丝是否松动（电机座、桨座）
- [ ] 检查三相线与电调连接是否牢固，绝缘层无破损
- [ ] 手动旋转电机，听是否有异响（轴承磨损信号）

### 清洁与保养

| 频率 | 项目 | 操作 |
|------|------|------|
| 每次飞行后 | 表面清洁 | 用软毛刷清除线圈槽内的灰尘与杂物 |
| 每 20 次飞行 | 轴承检查 | 检查轴承是否有虚位或异响，必要时更换 |
| 每 50 次飞行 | 轴承润滑 | 使用高速轴承油（如 SKF LGHP 2）润滑，每颗轴承 1～2 滴 |
| 撞击后 | 动平衡检查 | 检查电机轴是否弯曲、转子是否变形 |

### 常见故障排除

| 故障现象 | 可能原因 | 解决步骤 |
|---------|---------|---------|
| 电机不转/抖动 | 相线断线、电调故障、接线松动 | 检查三相线焊接点；更换电调测试 |
| 电机发热严重 | 过载、桨过大、通风不良 | 减小桨尺寸；检查工作电压是否匹配 |
| 飞行中异响 | 轴承损坏、磁钢脱落 | 更换轴承；检查转子内部 |
| 电机运转不平顺 | 桨座不平衡、电机轴弯曲 | 做桨平衡；检查轴心偏摆 |

> 更详细的故障排查请参考 [电机官方技术手册](https://www.rcsunnysky.com)。
