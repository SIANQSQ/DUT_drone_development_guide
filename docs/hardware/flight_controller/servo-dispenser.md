# 舵机投放器

## 设计背景

比赛过程中存在时间限制，因此需要在有限时间内快速完成水瓶的装配与投放。为提高装配效率，设计了一种基于舵机开闭控制的快速投放器。

## 结构方案

对水瓶外壳进行简单改造，并在外部加装磁铁。通过舵机带动机构开闭，使水瓶能够快速装配到投放器上；在执行投放时，舵机打开机构，完成水瓶的快速释放。

## 舵机安装注意事项

安装舵机杆件时，不要将连接螺丝拧得过紧。受机构运动角度影响，螺丝过紧会使舵机无法灵活开闭。

安装完成后，应保证能够用手推动或拉动舵机杆件，同时杆件不会自行脱落，以兼顾机构活动性与连接稳定性。

## 舵机控制方式

舵机的使用分为两种情况：

- **未上电时**：可直接用手推动或拉动舵机杆件，便于调试与检查机构运动状态。
- **上电后**：舵机处于锁定状态，不能直接手动推拉杆件。此时需通过网络传参程序进行控制，在控制页面右下角使用两个舵机开闭按钮，分别控制两个舵机的开闭，从而实现投放器的装配与投放动作。
