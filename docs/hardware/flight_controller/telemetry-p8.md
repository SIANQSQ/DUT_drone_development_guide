# P8 数传模块

P8 Radio 是 CUAV 雷迅创新的无人机超远程数传模块，用于在飞行控制器与地面站之间建立透明的数据链路。模块支持点对点和中继模式，最高空口速率为 345 Kbps，并可在 12--60 V 电源范围内工作。

> 本页根据 CUAV 官方产品页、官方文档和 2024-06-08 版《P8 模块产品说明书》整理。40 km 为地对空、郊区无遮挡条件下的参考距离；实际通信距离受环境、天线、配置和法规限制。

## 产品特性

- 工作于 840--845 MHz 无人系统专用频段。
- 支持跳频或固定频率、透明传输，以及点对点和中继通信。
- 空口速率最高 345 Kbps。
- 内置 BEC，支持 3S--12S 电池输入，即 12--60 V。
- 内置 TTL 与 USB 接口，天空端和地面端可互换使用。
- 采用全铝合金外壳，兼顾结构强度、耐腐蚀性与散热。

| 项目 | 官方参数 |

## 安装与连接

### 供电要求

天空端和地面端均需独立供电。推荐使用 3S--12S 电池，且电源最大输出电流必须大于 2.5 A。上电前必须连接天线。

不要用电脑 USB 口、飞控或输出电流低于 2 A 的移动电源为 P8 供电，否则可能因供电不足损坏模块。

### 连接飞控

使用 P8 专用线缆，将飞控的 `TELEM1`、`TELEM2` 或标为 `Radio` 的接口与 P8 的 `Data` 接口连接。

| 飞控类型 | 连接方式 |
| --- | --- |
| PixHack 系列 | 将 P8 接入飞控的 `Radio` 接口。 |
| V5+、V5 NANO、X7 系列 | 使用专用线缆连接飞控 `TELEM1` 或 `TELEM2` 与 P8 的 `Data` 接口。 |

## 出厂默认配置

| 项目 | 默认值 |
| --- | --- |
| 空口速率 | 115 Kbps |
| 接口波特率 | 57600 bps |
| 工作模式 | 广播模式 |

通常无需额外配置即可使用。如需修改设备 ID 或中继模式，请使用 CUAV 的 P8 配置指南。

## 配置步骤

P8 出厂时已经完成配置，通常可即插即用。仅在需要修改设备 ID、工作模式、空口速率或频点时进入配置模式。配置时，两个通信端的网络 IP、空口速率和频点必须一致。

### 进入 AT 配置模式

1. 使用 Type-C 将 P8 连接到电脑，并打开串口助手。
2. 使用以下任一种方式进入配置模式：

| 方式 | 串口参数与操作 |
| --- | --- |
| 按键方式 | 串口设为 `9600`、8N1、ASCII；同时按住 `CONFIG` 和 `RESET`，先松开 `RESET`，再松开 `CONFIG`。 |
| 指令方式 | 串口设为模块当前波特率，出厂默认 `57600`、8N1、ASCII；发送 `+++`。串口返回 `NO CARRIER ok` 表示已进入配置模式。 |

`+++` 指令**不需要**按 Enter。进入配置模式后的每条 AT 指令（包括最后一条）都必须按 Enter 换行；配置成功时设备会返回 `ok`。

### 查询当前配置

```text
AT&V
```

### 点对点通信示例

以下示例配置地面端为主机、天空端为从机：接口波特率 57600 bps、空口速率 276000 bps、网络 IP `725527`、发射功率 1000 mW。主机设备地址为 `1`，目标地址为 `2`；从机设备地址为 `2`，目标地址为 `1`。

```text
# 主机（地面端）
AT&F6 ATS102=2 ATS103=4 ATS104=725527 ATS108=30 ATS105=1 ATS140=2 AT&W

# 从机（天空端）
AT&F7 ATS102=2 ATS103=4 ATS104=725527 ATS108=30 ATS105=2 ATS140=1 AT&W
```

### 带中继的点对点示例

以下示例在点对点链路中加入中继机。主机与从机的网络 IP、空口速率和发射功率保持一致；中继机地址使用 `3`。

```text
# 主机（地面端）
AT&F6 ATS102=2 ATS103=4 ATS104=725527 ATS108=30 ATS105=1 ATS140=2 ATS141=1 AT&W

# 从机
AT&F7 ATS102=2 ATS103=4 ATS104=725527 ATS108=30 ATS105=2 ATS118=3 ATS140=1 AT&W

# 中继机
AT&F7 ATS101=1 ATS102=2 ATS103=4 ATS104=725527 ATS108=30 ATS105=3 ATS118=1 ATS140=1 AT&W
```

### 频点检查

频点设置并非日常必需操作。仅当两端其他参数一致仍无法通信时，检查频点是否相同；两端频点不一致时无法建立通信。

```text
# 查询当前频点
ATP0?
```

频点修改最多可设置 50 个频点。修改前应记录原始配置，并严格遵守当地无线电频谱法规；完整频点列表和修改格式请以 CUAV 官方配置指南为准。

## 地面站连接

### Mission Planner

连接硬件后，在右上角选择对应串口，将波特率设为 `57600`，然后点击 `CONNECT`。

### QGroundControl

连接 P8 后打开 QGroundControl，地面站通常会自动识别并连接。若未自动识别，可在“通信连接”中手动添加串口连接，并设置名称、类型、串口和波特率。

## 按键与故障排查

| 项目 | 说明 |
| --- | --- |
| `RESET` | 重启模块。 |
| 进入配置状态 | 同时按住 `CONFIG` 和 `RESET`；先松开 `RESET`，再松开 `CONFIG`。 |
| 电脑未识别串口 | 安装 P8 驱动程序。 |
| USB 连接后鼠标异常、无法通信 | 先为地面端供电，再为另一端供电；USB 启动时若另一端已有数据，电脑可能错误安装鼠标驱动。 |
| 指示灯熄灭或模块不工作 | 检查电源口最大输出电流是否大于 2.5 A，并确认两端均已独立供电。 |
