# P9 数传电台

## 产品简介

P9 数传电台是 P8 的升级旗舰型号，将最大通信距离扩展至 **30km**，发射功率提升至 **2W**，并引入双频冗余链路与 FHSS 自适应跳频机制。P9 专为超远距离 BVLOS 任务和复杂电磁环境下的高可靠通信而设计。

本项目中 P9 数传电台作为高可靠通信升级选件，配合 CUAV X25 EVO 飞控和 QGC 地面站使用。

## 产品特性

| 特性 | 说明 |
|------|------|
| **30km 超远距** | 2W 满功率搭配高增益天线，视距通信 ≤ 30km |
| **双频冗余** | 主/备双频段并发，主频受干扰时自动切换备频 |
| **双天线分集** | 两根天线独立接收，合并最优信号路径 |
| **FHSS 自适应跳频** | 检测到干扰信道自动跳频 |
| **AES-256 加密** | 军用级硬件加密 |
| **双串口输出** | 同时连接飞控 TELEM 1 和 TELEM 2，主备冗余 |
| **宽温工作** | -40°C ～ +85°C |
| **向下兼容 P8** | 可与 P8 数传混合组网 |

| 线序 | 功能 | 飞控端 |

| VCC | 5V 供电 | TELEM 1 口 5V |

## 配置步骤

### AT 指令示例

```bash
# 主频率 915MHz，备频率 868MHz
AT+FREQ1=915
AT+FREQ2=868

# 2W 满功率 + FHSS 跳频
AT+POWER=2
AT+MOD=2

# 空中速率 250kbps
AT+RATE=250

# 保存并重启
AT+SAVE
AT+REBOOT
```

### 飞控双串口参数

| 参数 | 值 | 说明 |
|------|------|------|
| `MAV_1_CONFIG` | `102` | TELEM 1 主链路 |
| `MAV_2_CONFIG` | `101` | TELEM 2 备链路 |
| `MAV_2_MODE` | `1` | 低带宽冗余模式 |

## 常见故障排查

| 故障现象 | 可能原因 | 排查方法 |
|---------|---------|---------|
| 距离不足 | 功率未设 2W、天线增益低 | `AT+POWER=2`；换 8dBi 高增益天线 |
| 链路频繁切换 | 主频受干扰 | 更换主频信道；确认 FHSS 已启用 |
| 双串口无效 | 飞控未配置备链路 | 检查 `MAV_2_CONFIG=101` |
| 数据延迟大 | 空中速率过低 | 提高至 500kbps |
| 黄灯不亮 | 备频未配置或天线未接 | 确认 `AT+FREQ2` 已设；检查 ANT2 |
